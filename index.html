ルール説明

  • 5～8の数字が三つ出てきます。
  • 得点は、それぞれこうなっています。

    1. 777が出たら 3 倍

    2. 8のゾロ目が出たら 2 倍！

    3. そのほかの数字でのゾロ目で終了した場合：+50コイン
    4. その他ゾロ目ではない数字で終了した場合：何ももらえない
  • 1ゲームあたり、基本5回回せます。
  • 必ずコインをかけてください（50以上）。
  • 不具合が発生した場合、近くのスタッフに言ってください。
  • 二回遊んだら次の人にゆずってください。

2. そもそもこれは何？

  • Python版を作り、それをHTMLにしたスロットゲーム。

手動スロットチームにお詫び

  • 倍率を変えるときは、下の設定を確認してください。
  • 数字は5～8を使用しています。

倍率を変更する手順

  1. script 内の MULTIPLIER を変更する。 
    const MULTIPLIER = {
    jackpot: 3,
    other_zorome: 2,
    other: 0
};
  2. 保存する（Command + S）。
  3. ブラウザを更新する（Command + R）。

3. 不具合が起きたとき

クリックしても進まない

  • 数字が表示されている最中は、少し待ってください。

最初からやり直したい

  • ブラウザを更新するか、トップに戻るボタンを押してください。

不具合が起きたとき

  • ブラウザを更新し、それでも直らなければ作成者に連絡してください。
